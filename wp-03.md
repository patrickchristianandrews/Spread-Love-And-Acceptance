# WP-03 — Domestic RACI Treaty

**Purpose:** a living agreement assigning exactly one Responsible and one Accountable name to every recurring household task, so ownership stops getting renegotiated by default every week.

- **Responsible (R):** does the task.
- **Accountable (A):** notices if it didn't happen and follows up. Can be the same person as R.

> **Before you start, run WP-02.** This is the longest session in the suite — 45 to 60 minutes of negotiating ownership. Don't attempt it at the end of a hard day. If either person's battery is high, move it.

**Why the second block is there.** The Preface opens on someone noticing the milk is low, and someone remembering a dentist appointment three weeks out. That work is the whole reason this framework exists, and it's the easiest to leave off a chore list — it has no start time, no finish, and nothing to point at when it's done.

An invisible-column row usually has the same Responsible and Accountable name, and that's fine. Naming it is the point. A household where one person holds every row in that block has found something a tidy kitchen was hiding.

## Part B — Amendment process

This treaty isn't permanent — it's meant to be renegotiated when life changes (new job, health issue, new baby, etc.), not silently reassigned when one person just starts doing more. To amend:

1. Either person can call for a review at the weekly closing (Chapter V).
2. Changes are written into the table above, not just agreed verbally.
3. Both people initial the change, and log it below.

A treaty with no amendment history is almost always a treaty nobody is using. The log also answers the question WP-04 asks each month — did last month's fix actually hold — which needs a date to be answerable.

**On removals.** A task only comes off this treaty through a WP-04 Part B decision — classified as a standard in question, discussed, and agreed not to be something the household requires. Log it as Removed with the date. Quietly deleting a row because nobody wants it is not a removal. It's the same unowned task, now unwritten.

## Feeds into — Ownership Clarity Score

**Ownership Clarity Score** (for the Verdict Engine, Chapter II): count tasks with both an R and an A filled in, divided by total tasks listed. This is the `ownership_clarity_score` input.

> Don't raise the score by shortening the list. Deleting the three tasks nobody owns improves the arithmetic and changes nothing in the house. If a task is real and unowned, it belongs here as an unowned row — that's the row this score exists to surface.
>
> The same arithmetic runs the other way, and it's worth expecting: **adding tasks you'd never written down before will lower the score**, because they arrive as new unowned rows in the denominator. A month where the number drops because five invisible tasks finally got named is a better month than one where it held steady on an incomplete list.

> **What this score cannot see.** A treaty where one person is Responsible and Accountable for all twenty rows scores a perfect 1.00. Ownership is completely clear; the arrangement may still be indefensible.
>
> Clarity and fairness are separate measurements, and this one only reads clarity. The split is what WP-01 measures, and the two are meant to be read together — a 1.00 here alongside an 80/20 split there is not a household that has solved anything. It's a household that has written down exactly how lopsided it is, which is a real and useful first step, and not the last one.
