The 6-Week Program

A guided sequence through the workpapers that already exist — no new tools, just an order to use them in.

Purpose: the workpapers work better in a deliberate order than dropped on someone all at once. This sequence uses only the five workpapers that are actually built and reviewed — WP-01, WP-02, WP-03, WP-09, and WP-13 — each introduced once the previous week's data makes it useful.

As new workpapers ship, this curriculum will be revised to include them. It's a living sequence, not a fixed track.

Week 1

Just Observe

WP-01 Field Audit

Run the 7-day Field Audit for the first time. No interpretation yet, no fixing anything — just log what actually happened, honestly, before either person's memory of the week hardens into a story.

Week 2

Add the Daily Habit

WP-01 continues · WP-02 introduced

Keep logging the Field Audit. Introduce the Battery & Stress Meter as a quick daily self-check — independently, about yourself only — so stress load becomes visible before it gets mistaken for something else.

Week 3

Assign Ownership, With Data

WP-03 Domestic RACI Treaty

Now there are two weeks of real Field Audit data to work from. Fill out the RACI Treaty informed by what actually happened, not by guessing or by whoever argues more persuasively.

Week 4

Retune Before Responding

WP-09 The Tone Transducer & Filter

By now there's likely been at least one hard conversation. Introduce the three-question self-check before sending a message that landed hard — a tool for your own reaction, not for reading anyone else's.

Week 5

Small Corrections, Daily

WP-13 Phase-Locked Loop Protocol

Start the 90-second daily check-in habit. The goal is small, constant corrections instead of letting friction build toward a bigger blowup later — the exact failure mode the earlier weeks were making visible.

Week 6

Full-Cycle Review

WP-01 Field Audit, run again

Run a second week of the Field Audit and compare it against Week 1. This is the actual test of whether the previous five weeks changed anything measurable — not a feeling, but the same log, run twice.

What this program is not: a guarantee that six weeks fixes anything. It's a sequence for using real tools in a sensible order. Some weeks will need more than a week; that's fine — move at the pace that's actually true for you, not the pace on this page.
