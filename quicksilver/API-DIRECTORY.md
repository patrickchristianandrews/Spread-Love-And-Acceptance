# Quicksilver API directory

Every cloud service Quicksilver can use (63 of them), by task. In each task: free ones first, then free to start, then paid, with what the free plan gives you, what it costs after, and a link to get its key. A service appears under every task it is good at.

Free allowances and prices are as of November 2026 and change often: the "prices" link shows today's. Quicksilver works without any of these; they are optional additions. The same list is in the app under Guide → Best cloud AIs, and under Models → Connect an API → API directory.

Tasks: 💬 Everyday chat · 🧠 Hard reasoning & maths · 💻 Coding · ✍️ Writing · 🔎 Research with sources · 👁️ Reading photos & screenshots · 🔓 Uncensored · 🖼️ Making pictures · 🪄 Editing photos · 🎬 Video · 🎵 Music (full songs) · 🎙️ Voices · 🌍 Translation

## 💻 On your own PC or server

Free, and nothing leaves your PC. Quicksilver connects to these if you already run them.

- **LiteLLM proxy (your server)**: Free: your own LiteLLM proxy, which can route to any provider. Add its key if you set one.
- **Ollama (on this PC)**: Free: runs on this PC with no key.
- **Giant models (colibri, on this PC)**: Free: colibri runs models bigger than this PC's memory, streaming from the SSD. Set up from Your PC → Giant models.
- **LM Studio (on this PC)**: Free: runs on this PC with no key.
- **Strata (on this PC)**: Free: Strata runs very large models (up to ~125B) on a single consumer GPU by streaming weights from disk — no key. Start Strata first; it serves an OpenAI-compatible API on localhost:8080 (change the port here if yours differs).
- **Jan (on this PC)**: Free: runs on this PC with no key. Start Jan's local API server first.
- **llama.cpp server (on this PC)**: Free: a llama-server you run yourself.
- **vLLM / LocalAI / TGI (your server)**: Free: any OpenAI-compatible server on this PC or your network.
- **KoboldCpp (on this PC)**: Free: runs on this PC with no key.
- **GPT4All (on this PC)**: Free: turn on GPT4All's local API server first.
