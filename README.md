# spreadloveandacceptance.com

Source for The Objective Ledger (TOL-OS) site. The repo root is the site root: GitHub Pages serves it as-is, so a file's path is its URL (`workpapers/wp-01.html` → `spreadloveandacceptance.com/workpapers/wp-01.html`). Every file in the repo is public, including `.md` files and this README.

## How the site fits together

- **Navigation and membership** live in one file: `assets/js/site.js`. The `SECTIONS` list at the top is the menu for every page, in reading order. `RIBBON` picks which sections appear in the top bar (Start here, Self-discovery, Relationships, Book, Workpapers, Tools, Media); each opens a short dropdown of its page titles. "Everything on the site" and the phone Menu show all sections collapsed, one open at a time. New media pages go in the `media` section. To add a page, add a line there and put these two lines in the page's `<head>`:
  ```html
  <link rel="stylesheet" href="/assets/css/site.css">
  <script src="/assets/js/site.js" defer></script>
  ```
- **Simple first, dig deeper on demand.** A page's normal address is its simple version: a short lede, a few numbered ideas, and a "Try this" box. The full version sits beside it as `<name>-in-depth.html` (for example `book/chapter-2.html` and `book/chapter-2-in-depth.html`). Each idea ends with a pickaxe link that jumps to the matching section of the full page:
  ```html
  <a class="dig" href="/book/chapter-2-in-depth.html#inputs">Dig deeper: where each number comes from</a>
  ```
  Give every section on the in-depth page an `id` to jump to. Set `deep: true` on the page's line in `SECTIONS`: the menu then shows its own Dig deeper link, and the in-depth page shares the simple page's members lock and previous/next links. Split so far: Turning Toward, the book, every workpaper and REPORT-01, PROG-01, and the guide pages (How it works, Is this right for you, Relationships, Check-ins, Wired Differently, the Frequency Framework, Stories from Philosophy, Contents, Ways in, Suite Index, Program Overview, About). The home page keeps its own full layout and is not split. Interactive tools and calculators are not split: the tool itself is the simple version.
- **Members-only pages:** set `paid: true` on the page's line in `SECTIONS`. While `freePreview: true`, those pages open for anyone who signs up with an email (sent to Buttondown). The lock only runs in the browser: the page's HTML is still public, so treat it as a sign-up prompt, not protection.
- **Members list:** `data/members.json` holds SHA-256 fingerprints of member emails, never the addresses. Manage it with `python3 manage-members.py add|remove|check|count <email>`, then commit and push.
- **Household dashboard:** `dashboard.html` uses Supabase. Setup is in `dashboard-setup.md`, the schema in `supabase/schema.sql`. Only the anon/publishable key goes in `assets/js/dashboard-config.js`, never the service_role key.

## Calm features

- **The Night Garden** (`night-garden.html`, `assets/js/night-garden.js`): breathing, fireflies and a lily-pond puzzle on one canvas. No timers, no losing, no streaks; the garden is saved only in the visitor's browser (`tol-night-garden-v1`). Sound is on by default and box breathing always starts with sound; the Sound button turns it off.
- **Quiet Words** (`quiet-words.html`, `assets/js/quiet-words.js`): a calming word search. 499 themes in American English (loaded in small chunks from `assets/js/puzzles/qw-themes-*.js`), a theme of the day picked by the date, and a new grid every play; each word leaves a kind line, and a word counts wherever it's found. No timer or score; only a finished-puzzle count is kept in the browser.
- **Workpaper Suite** (`workpapers/fill/suite.html`, `tol-suite.js`, `tol-suite-paths.js`, `tol-suite-pdf.js`): choose a road (yourself, each kind of relationship, or the 6-week program, defined in `tol-suite-paths.js` from the relationship map and PROG-01) and its workpapers line up in groups. Sheets are filled in on the page, or brought in from draft files, suite files or filled-in fillable PDFs (read back by `readFilled`, which also opens compressed object streams). It makes a fillable, printable PDF (real form fields, bookmarks, a cover "road") and a report grouped by the road's steps, with changes over time and a "worth keeping close" page. Every single fill-in page also has a Fillable PDF button and opens its own filled PDF. Like the other fill-in pages, nothing typed is stored or sent.
- **Pause & Play** (`pause-and-play.html`, `assets/js/pause-and-play.js`): the page for all the calm games, with your level and true puzzle counts (no streaks). The Night Garden plays behind it, silently, from `garden-backdrop.html` (night-garden.js in its `data-ambient` mode, which never changes the visitor's saved garden).
- **Word Bloom** (`word-bloom.html`, `assets/js/word-bloom.js`): a letter-wheel game. Swipe across the petals to spell words that fill a small crossword; any everyday word that fits a slot fills it, and other real words go in a bonus jar (`bloom-dict.js`, a family-friendly dictionary made by `make_bloom_dict.py`).
- **Quiet Crossword** (`quiet-crossword.html`) and **The Daily Ledger Crossword** (`daily-ledger-crossword.html`), both run by `assets/js/quiet-crossword.js`: small free-form crosswords, and newspaper-style grids from a 5x5 Mini to a 13x13 Big Sunday. Today's puzzles are picked by the local date, the same for everyone: a Mini every day, a bigger grid through the week and the Big Sunday on Sundays (a themed Gentle crossword on Quiet Crossword); the whole collection stays under the size buttons. On-screen keyboard and a bigger-squares option for phones.
- **Levels** (`assets/js/game-levels.js`): every word game (with Quiet Words) has five difficulty levels, "Next" in order (moving up a level at the end), "Random" at the same difficulty, remembers what you've played so puzzles don't repeat, and shows a tip from the program (from the mini-dive glossary) after each puzzle. Puzzles live in `assets/js/puzzles/` (about 500 small chunk files), loaded when needed: about 6,400 Word Bloom wheels, 6,200 Quiet Crosswords, 1,860 Daily Ledger grids and 499 Quiet Words themes. Each browser remembers what it has seen, and once a level is fully played, new puzzles are made on the spot.
- **Word lists and puzzles** (`tools/word-games/`): `lexicon.py` builds the safe vocabulary with clues from Open English WordNet 2023 (CC BY 4.0), keeping a word only if every meaning passes: no disparaging, obscene or slang senses, nothing under kept-out categories (weapons, crime, illness, death, drugs and so on) or formed from them, no definitions that mention them, nothing that reads as negative (VADER sentiment), and no names. `gentle-words.txt`, `clues.py`, `clues_more.py`, `clue_bank.py` and `clue-bank/*.txt` hold the hand-picked words and hand-written clues (about 1,300 answers), which always win. Every crossword clue and answer passes `clue_check.py` (tense and number, the answer inside its clue, duplicate clues, known-bad and vague clues, British spellings, touchy words); `good_clues.py` keeps only dictionary clues from a word's common meanings. `make_crosswords.py` makes both crosswords (`check` and `fix` keep the served banks clean); `make_levels.py` makes Word Bloom, then `make_bloom_dict.py` and `clean_bloom.py` tidy it; `make_themes.py` makes the word-search themes. Also needs `pip install nltk` and `nltk.download('wordnet')` for sense counts. Needs `pip install wn wordfreq english-words vaderSentiment` and `python -c "import wn; wn.download('oewn:2023')"`. Add words to the lists rather than editing the generated files.
- **Levels and the growing background** (`assets/js/rewards.js`): every level finished in a calm game counts (no streaks). At a steady pace (every six levels at first, slowing to twelve) something new appears in the garden behind every page (a tree and swing, koi, wind chimes, paper boats, a bridge, a blossom tree, aurora, fairy lights, a balloon, a hammock, rainbow lanterns, owls, butterflies, meteors, a gazebo, then more fireflies), drawn by `night-garden.js`; each one joins in with the animals (the swing, the bridge, the hammock, the gazebo, leaping koi, owls whose eyes follow the fun). `keepsakes.html` is "My garden": everything that has arrived (each can be switched off in the background) and the constellations found and named in the Night Garden. A new arrival shows on a game's own finish card or as a soft note, never as a second pop-up. The two dogs roam, play, hug and high-five in it. Kept in this browser only.
- **Music** (`assets/js/calm-music.js`): shared by the Night Garden and the word games; the Night Garden, Word Bloom and Quiet Crossword use its slower, softer `calm` mode. Soft pads drift through four chords (8 seconds each, two box-breathing counts) with a sparse kalimba-like melody; game sounds use `note(i)` so they always fit the chord playing now.
- **Tips library** (`assets/js/tips.js`): about 300 "Little tip for today" entries in 16 topics, loaded on demand by `site.js`, which prefers topics that fit the page's section.
- **Breathe button**: `site.js` adds a breathing break to every page (1, 3 or 5 minutes): a countdown ring, one grounding prompt per breath (`FOCUS`), and soft sound made in the browser (`breathSound`: a stereo chord in a generated hall, an ocean that follows the breath, singing bowls at each turn). Sound is on by default and remembered per browser; both sounds ask iPhones for media playback so the silent switch doesn't mute them. Pages opt out with `<body data-no-breathe>`.
- **The logo and mascots** live in `assets/img/`: `logo.svg`, `logo-stacked.svg` and the marks (`logo-mark.svg`, `logo-mark-dark.svg`, `logo-mark-wink.svg`: two friends, two pups and a small golden heart), shown with how to use them on `brand.html`. There's one mascot per section in `assets/img/mascots/`, placed beside page titles by `site.css`. App icons and the favicon are in `assets/icons/` (rendered from `assets/icons/icon.svg`), with copies of `favicon.ico` and `apple-touch-icon.png` at the root.
- **Drifting hearts and bubbles**: part of the watercolour wash in `site.css` (`.tol-bub`, `.tol-heart`). Bubbles are blown up, float and pop; hearts crack and heal. They stay still for visitors who ask for reduced motion.
- **The site as an app**: `manifest.webmanifest`, `sw.js` and `offline.html` let visitors add the site to their home screen and open it offline. `site.js` adds the icon and manifest tags to every page and offers, once, on a phone and on a later day, to show how. The service worker fetches pages from the network first, so an update is never hidden behind a saved copy; bump `VERSION` in `sw.js` when its file list changes. The word-game chunks in `assets/js/puzzles/` aren't precached; each is saved the first time a game loads it.
- **Gentle welcome-backs**: Today’s Weather and Turning Toward greet a returning visitor using only what’s saved in their own browser. No streaks, no “you missed”.
- **Wording**: simple pages and the menu use warm, everyday words; formal names (WP-03, the Deficit Audit and so on) stay in `.formal` spans, the small code line and the full versions.

## Rules to keep


- **Don't move `workpapers/calculators/calc01-solvency.html`.** That URL is printed in the member bundle.
- **Shipping anything means updating all three status pages:** `telemetry.html` (the counts), `suite-index.html` (every component named) and `roadmap.html` (what's next). Where they disagree, `suite-index.html` wins. Denominators never shrink to raise a percentage; if the plan changes, say so on the page.
- **One copy per page.** Before uploading a new version, check where the current one lives (search the repo) and replace it there instead of adding a second copy under another name.
- **Use root-relative links** (`/book/chapter-1.html`) so pages work from any folder.
