# WP-09 — Tone Transducer & Filter

**Purpose:** a practical checklist for "retuning" before responding, operationalizing the Radio Frequency Paradigm from Chapter I. This does not involve recording or analyzing anyone's actual voice — it's a self-check applied by each person to their own next message.

Two directions. The **transducer** runs outbound: it converts what you're about to send. The **filter** runs inbound: it decides how much weight to give what you just received. Neither is for grading the other person's delivery.

## The transducer step — before you speak or send

A transducer converts one form of signal into another. Here, it means converting a raw internal reaction into something the other person can actually receive. Before responding to something that landed hard, run it through three questions:

1. **What's the fact underneath this?** (One sentence, no adjectives.)
2. **What's the feeling underneath this?** (Name it — frustrated, tired, unseen, rushed.)
3. **What's the actual ask?** (What do you want to happen next, specifically?)

Write all three down before responding, even mentally. A message built from fact → feeling → ask transmits far more cleanly than one built from the raw reaction.

## The filter step — before you react to what they said

The filter runs the other direction: deciding how much weight to give an incoming message before responding to it.

| Check | Yes / No |
|---|---|
| Is this about a specific, nameable task or event? | |
| Would I read this the same way if I weren't already at high saturation (WP-02)? | |
| Is there a neutral interpretation that also fits what was said? | |
| Am I responding to their words, or to a pattern from a past conversation? | |

If saturation is high or the neutral interpretation hasn't been ruled out, use a neutral refusal or a pause script (WP-01) before continuing.

## Worked example

- **Raw reaction:** *"You never think about anyone but yourself."*
- **Fact:** "The trash wasn't taken out before pickup."
- **Feeling:** "Frustrated, and a little unseen since I mentioned it twice."
- **Ask:** "Can we agree on a fixed day/time for trash so it's not something I have to keep bringing up?"

Same underlying issue, transmitted on a frequency the other person can actually tune into.
