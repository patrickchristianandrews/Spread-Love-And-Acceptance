# WP-12 — Same moment, different speeds

*Also called the Carrier Frequency Audit.*

**Purpose:** to map mismatched pace. One person is moving fast, the other is at the end of their capacity and moving slowly, and the conversation produces noise neither of them meant. A difference in tempo, not in willingness. The sheet looks at it moment by moment, then turns the biggest gap into one small agreement.

**How often:** once, together, in about 20 minutes. Again every few months, or after a big change.

## Part A — Each person's speed

Each person fills in only their own rows, ideally before seeing the other's. Answer for how you really are on an ordinary day.

- **Speed:** Right away · Within the hour · Later the same day · After a night's sleep
- **Talk:** Quiet time first · A few words, then act · Talk it all through
- **Urgency:** Low · Medium · High
- **What helps me** (optional): a heads-up first, a time we'll decide by, ten minutes on my own

| Something breaks or goes wrong at home | | | | | |
| One of us is upset about something | | | | | |
| Deciding what to do with free time | | | | | |

Swap in your own moments. Every answer is a normal way to be.

## Part B — Where your speeds differ

For each moment, count how many steps apart the answers are on each list (Right away to After a night's sleep is 3 steps; Low to High is 2). Two or more steps in total is worth an agreement. Start with the biggest total. Look for speed flips: the fast one about plans may be the slow one about bills.

## Part C — One small agreement

Give the faster person a way to start and the slower person a time to land. Shapes that work: flag now, decide later; a pause with a time on it; one line first, then an hour; the faster one gathers facts, the slower one decides by an agreed time. Try each for two weeks.

## Made-up example

Rosa and Tom keep snapping about plans and the post.

| Moment | Who | Speed | Talk | Urgency |
|---|---|---|---|---|
| A plan changes at the last minute | Rosa | Right away | A few words, then act | High |
| | Tom | Later the same day | Quiet time first | Low |
| A bill, letter or form needs dealing with | Rosa | After a night's sleep | Quiet time first | Low |
| | Tom | Right away | A few words, then act | High |

Agreements: "When a bill comes, Tom flags it the same day; we sort it together on Sunday morning." "When plans change, Rosa says the new plan in one line, then gives Tom an hour before anything is decided."

## Honest note

There is no study behind these particular questions. It is a structured way to talk about a difference most people recognise. Not a compatibility test and not a diagnosis.
