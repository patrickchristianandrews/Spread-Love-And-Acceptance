# Amazon KDP, step by step

This guide walks through every KDP screen, in the order KDP shows them, for each book in the package. Every value is copied from the built files and from listing-kdp.md, so the titles, page counts, spine widths and prices are the real ones from this build.

Anything marked **[OWNER]** is your decision. The recommendation is given next to it.

Field names were checked in October 2026 against KDP’s help pages, through web search, because kdp.amazon.com could not be opened from the build machine. Where a box could not be confirmed, the guide says so. KDP changes its screens from time to time, so if a box is named differently, look for the one that means the same thing.

## The order to do things in

1. Before you start: nothing to buy. Each paperback gets a free KDP ISBN on its Paperback Content screen, and the Kindle editions need no ISBN.
2. Publish the paperbacks first, one at a time, and order a proof of each. Publish only after the proof is right.
3. Prices follow the owner’s rule: a paperback under 100 pages is a short edition at $9.99, anything longer is $14.99. The short editions (the pocket guide and the workbook) come after the books here, each under its own name. At $9.99 the color workbook can’t use Expanded Distribution, so it is Amazon only; every other book is Amazon only by choice.
4. Then the Kindle editions. Use exactly the same title, subtitle and author, so Amazon links each Kindle edition to its paperback.

## The AI questions (every book asks them)

**PRIVATE. Answer this in the KDP form. It is not printed in the book, and it is not shown on the site or on the product page.**

KDP asks, on the Content screen of every book, whether you used AI-based tools to create the book’s **texts**, **images** or **translations**. You answer each one separately. The answer is for Amazon only.

**What the words mean (KDP’s definitions, as reported in October 2026):** “AI-generated” means an AI tool created the actual words or pictures, even if you then edited them. That must be disclosed. “AI-assisted” means you created the work yourself and used AI only to brainstorm, edit, check or improve it. That does not need to be disclosed.

**The choices for each question** (as reported, so check the screen) are “None,” “Some sections, with minimal or no editing,” “Some sections, with extensive editing,” “Entire work, with minimal or no editing” and “Entire work, with extensive editing.”

**[OWNER] Only you can answer, because only you know how each book was made.** Answer truthfully. The words were drafted with AI writing tools, and the covers, characters and figures are drawn by code written with an AI tool. That makes the texts and the images “AI-generated” for the entire work; on each screen, choose the editing level that is true (only you know how much you edited). Translations: “None.” Never answer “None” or “No” on texts or images to make a book look more human-made than it is.

## If the previewer complains

- Most problems the previewer reports for these files come from choosing the wrong trim size or ink on the Content screen, so check those first.
- If it says the cover is the wrong size, check that the page count KDP shows matches the page count in the table for that book; the spine is calculated from it.
- If it flags text near the edge on a page with a QR code or a picture, look at that page in the PDF yourself. The files were built with safe margins, and the previewer sometimes warns about pictures that are meant to sit there. If unsure, ask KDP support before publishing.
